About

A lightweight and fully functional Patient Management System built with FastAPI, featuring patient creation, update, delete, sorting, and automatic BMI & health verdict calculation.

Tech Stack: FastAPI • Python 3.10+ • Pydantic • JSON Storage • Uvicorn

Features: Create ✨ Update ✨ Delete ✨ View all ✨ View by ID ✨ Sort by height/weight/BMI ✨ Search by name/city ✨ Filter by age & gender
